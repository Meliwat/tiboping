# TiboPing v0.1 Implementation Plan

**Design source:** `docs/superpowers/specs/2026-08-01-tiboping-v0.1-design.md`  
**Execution style:** test-first, small commits, one deployable container  
**Runtime:** Node.js 24 LTS, TypeScript, Fastify, React, SQLite

The repository uses npm workspaces. `@tiboping/core` contains network- and database-free domain types and classification. `@tiboping/server` owns all durable and external behavior. `@tiboping/web` builds a static SPA copied into the server's production assets.
